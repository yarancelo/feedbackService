# Банк идей и обратной связи

## Использование

- **Анонимно**: автор не сохраняется и не попадает в недельный зачёт.
- **Скрыть автора**: админ видит автора, но на стене идея показана анонимно; идея участвует в зачёте.
- **Показать автора**: на стене видны ФИО и отдел, идея участвует в зачёте.

На стене есть только идеи со статусом `accepted`.

## Контракты API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/employees` | Справочник сотрудников |
| POST | `/api/ideas` | Отправить идею |
| GET | `/api/wall?page=` | Стена принятых идей |
| GET | `/api/ideas` | Админский список с фильтрами |
| PATCH | `/api/ideas/{id}/status` | Модерация |
| DELETE | `/api/ideas/{id}` | Удаление |
| GET | `/api/leaderboard?week=YYYY-Www` | Лидеры недели |

## Недельный рейтинг

Учитываются только `accepted` идеи с сохранённым автором. Неделя определяется по дате подачи, ISO-календарю и `Europe/Moscow`. При равном количестве выше автор, чья последняя зачётная идея подана раньше.

## Миграция

Миграция `0002_ideas` переименовывает `feedbacks` в `ideas`, добавляет нужные поля и сохраняет старые записи как принятые анонимные идеи.
