Логотип для стены улучшений

Поместите PNG-файл логотипа в эту папку с именем `logo.png`.
После следующей сборки Docker он будет доступен на сайте по адресу `/logo.png`.

В интерфейсе уже есть контурная заготовка «ЛОГОТИП PNG». Она намеренно не
ссылается на файл до его загрузки, поэтому приложение не покажет битую картинку.
